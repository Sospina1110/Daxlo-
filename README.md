# Daxlo

Landing page de **Daxlo** — Coaching 1 a 1 para aprender inteligencia artificial.

> Aprende. Aplica. Avanza.

## Sobre Daxlo

Somos Martín Zárate y Santiago Ospina, dos estudiantes de Administración del CESA que viven y respiran inteligencia artificial. Creamos Daxlo para que aprender IA sea tan simple como tener una conversación. Uno a uno. A tu ritmo. Sin humo, sin relleno, sin complicaciones.

## Stack

- HTML + CSS (vanilla, sin framework)
- Inter font
- Video de fondo en loop
- Mobile-first, responsive
